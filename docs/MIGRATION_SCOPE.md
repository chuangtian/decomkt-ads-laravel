# Decomkt Ads Laravel migration scope

The Next.js repository is the read-only behavioral reference. This repository is an independent Laravel 13 implementation.

## Architecture

- Laravel 13 / PHP 8.4
- Vue 3 + TypeScript + Inertia 3
- MySQL 8.4
- Redis for cache, sessions and queues
- Laravel queue workers and scheduler
- Docker Compose local environment

## Functional areas

- Authentication, email verification, password reset and profile
- Roles, permissions, employees and per-store access
- Store configuration, credentials and runtime settings
- Executive dashboard and ecommerce reporting
- Shopify and Amazon integrations
- Facebook, Google, TikTok, Bing and Criteo advertising
- SEO/GEO, social media, influencers, EDM and affiliate marketing
- Design operations, reputation monitoring and risk synchronization
- Task board, calendar, notifications and team collaboration
- AI marketing workflows and scheduled reports
- Shopify embedded student-discount application

The implementation uses generated Eloquent domain models, Laravel controllers, encrypted configuration services, Redis-backed queues/sessions/cache, RBAC middleware, Inertia pages and feature tests. External vendor data remains credential-dependent and reports an explicit configuration status until real credentials are supplied.
